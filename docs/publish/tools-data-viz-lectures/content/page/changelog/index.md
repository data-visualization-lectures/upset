## 更新情報

### 2026年10月7日（可視化）

- 新規ツール「UpSet」を追加しました。複数集合の交差と要素を、マトリックスとバーで探索できます。


### 2026年10月5日（可視化）

- 新規ツール「Tree Chart Builder」を追加しました。階層データから、ツリーマップ、ラディアル・ツリー、つららチャート、サンバーストの4種類を作成できます。


### 2026年10月4日（可視化）

- 新規ツール「重み付き有向フローマップ」を追加しました。地点間の移動や取引を、向きと量のある流れとして世界地図や日本地図に描けます。往復で値が違っても、2本の矢印を並べて読み分けられます。

### 2026年9月25日（可視化）

- 新規ツール「Interactive Chart Builder」を追加しました。ストリームグラフ、バンプ・チャート、ビースウォーム・プロット、ベン図 / オイラー図、時系列散布図、サークル・パッキングの6種のテンプレートから、動きのあるインタラクティブなチャートを作成できます。

### 2026年9月19日（可視化）

- 新規ツール「Parallel Sets」を追加しました。カテゴリの組み合わせと件数を、帯でつなぐパラレル・セットで可視化できます。
- 新規ツール「Matrix Table Chart」を追加しました。クロス集計表をリストに変換せず、ヒートマップ、モザイク、積み上げバー、パラレル・コーディネイト、散布図行列、コード・ダイアグラム、隣接行列で可視化できます。

### 2026年9月8日（可視化）

- 新規ツール「Race Chart Builder」を追加しました。バー・チャート・レース、バンプチャート、折れ線、散布図、スロープグラフの5種から選び、時系列データの順位や値の変化をアニメーションで作成できます。

### 2026年9月1日（可視化）

- 新規ツール「投影法の選び方」を追加しました。角度・面積・距離のどれを守るかを決めて、地図投影法を選べます。

### 2026年8月31日（可視化）

- Cytoscapeで、表データからネットワーク図を作成できるようにしました。次数やコミュニティで色・サイズを付け、凡例付きで書き出せます。
- Word Cloudで、複合名詞の結合、語リストからの除外、ワードバブル、見た目のプリセットに対応しました。

### 2026年6月27日（共通）

- ツール一覧ページを見直し、ツール名・用途・カテゴリから検索し、カテゴリで絞り込めるようにしました。各ツールの詳細ページやツール本体にも一覧から直接アクセスできます。
- データ可視化・データ加工のマイページを、作業開始用のホーム画面として整理しました。保存プロジェクト、サンプルデータ、公開プロジェクト、目的別のツール導線から、次の作業を始めやすくしました。

### 2026年6月20日（可視化）

- コロプレスとカルトグラムで、対象範囲をツール内で選べる導線に変更しました。日本全体の地図と都道府県内の地図を、別々の入口から開く必要がなくなりました。
- 多変量コロプレスに対応しました。

### 2026年6月18日（加工）
